# Blockwright Blocks

The companion plugin for the [Blockwright](https://wordpress.org/themes/blockwright/) block
theme. Adds custom blocks (Icon Box, Icon List, Stat Counter, Timeline), a Light/Dark Toggle,
dynamic-content bindings, and a curated icon collection that registers into the core Icon
block picker on WordPress 7.1 and later. Works with any block theme and degrades gracefully.

**Install from WordPress.org:** https://wordpress.org/plugins/blockwright-blocks/

Theme: https://wordpress.org/themes/blockwright/
